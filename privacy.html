プライバシーポリシー

アプリ名：放課後ハンドバトル　／　制定日：2026年10月24日

このページは、iPhoneアプリ「放課後ハンドバトル」（以下「本アプリ」）で、どの情報をどのように扱うかを説明するものです。

1. カメラの映像について

  • 本アプリは、手や腕の動きで技を出すために、iPhoneの前面カメラを使います。
  • カメラの映像は、iPhoneの中だけで手や腕の位置を読み取るために使います。映像・写真・音声を、開発者や第三者のサーバーへ送ることはありません。
  • 映像を保存することもありません。
  • マイクは使いません。

2. 端末に保存する情報

  • 端末の中だけに保存する情報：連勝の記録、勝った回数、実績、えらんだ見た目、速さの設定、チュートリアルの進み具合などの遊びの情報。
  • これらの情報は外部へ送りません。アプリを削除すると消えます。
  • 「記録を書き出す」を押したときだけ、記録をファイルとして書き出します。書き出したファイルの扱いは、利用者の判断によります。

3. 集めない情報

  • 名前、メールアドレス、電話番号、位置情報、連絡先などの個人情報は集めません。
  • 利用状況の分析ツールや、広告のための追跡は使っていません。

4. 通信について

本アプリは、遊ぶために必要なデータをすべてアプリの中に持っています。遊んでいるあいだにインターネットへ通信することはありません。

5. 子どもの利用について

本アプリは個人情報を集めないため、子どもが遊んでも、個人情報が外部へ送られることはありません。

6. このポリシーの変更

広告の表示など、情報の扱いが変わる機能を加えるときは、このページを更新し、アプリの中でもお知らせします。

7. お問い合わせ

このポリシーや本アプリについてのお問い合わせは、お問い合わせページ（GitHub の Issues）からお送りください。投稿には GitHub のアカウントが必要です。投稿した内容は公開されるので、名前や連絡先などの個人情報は書かないでください。
